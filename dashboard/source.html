Source

The code behind this site, served as a git repository from this domain. No account, no platform, nothing to sign up for.

git clone https://brainonbnb.com/source.git

It is a normal repository over plain HTTP. Any git client can read it; nothing here needs a token.

Why it is hosted here and not on a platform

Because in five weeks two of them stopped being an option. Our GitHub account was flagged by an automated system on 24 July 2026, which hides every repository under it; the appeal has been open ever since. Codeberg changed its Terms of Use on 21 July 2026 to bar both cryptocurrency projects and projects written largely with generative AI tools, and this project is plainly both.

A third platform would be the same bet placed a third time. This is a directory on infrastructure we already run, so it cannot be taken away — which felt like the more honest thing to depend on.

What is in it

  • The marketplace at /registry and everything behind it.
  • The agent service: x402 payments, ERC-8183 hiring, the live telemetry.
  • The token infrastructure — buy-back and burn workers, the liquidity tooling.
  • Every audit script, each with its own --self-test.
  • The census data: what we actually measured about the agents on this chain.

Picture material is not included — sticker frames, NFT card renders and hero illustrations are 401 MB of the working repository and are already served from this site. The generators that produce them are in. MIRROR.md in the repository lists exactly what was left out and where it lives instead.

Reading it without cloning

The Library on the home page carries the same code as browsable bundles, grouped by subsystem.

What is verifiably not in it

No credential of any kind, in the tree or in its history. That is measured rather than asserted: scripts/secret-audit.mjs reads every blob, derives an address from every 32-byte hex value it finds, and compares it against the wallets this project actually controls — because a transaction hash and a private key are indistinguishable by shape, and this repository holds thousands of the former. The publication step refuses to run unless that audit comes back clean.
